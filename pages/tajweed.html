Tajweed rules and colours

Tajweed annotations come from Quran Foundation Content APIs. Explicitly tagged rules and automatically detected heavy letters (Tafkhim) are coloured — the Arabic text itself is never changed.

Data and colours

Rule identities follow Quran Foundation Content API Tajweed tags; Tafkhim is detected locally from the seven heavy letters. This guide uses CSS colours; the reader uses the QCF V4 per-page glyph fonts.

Tajweed colours are a visual guide from tagged Qur’an data, not a substitute for learning from a qualified teacher.
